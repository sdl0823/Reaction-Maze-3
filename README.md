# 反應迷宮 (Reaction Maze)

這是一款考驗反應能力與策略思維的網頁遊戲。玩家需要在動態變化的迷宮中，快速反應並避開障礙物，在限定時間內到達終點。

## 遊戲特色

- **簡單但具挑戰性的操作**：使用方向鍵或WASD控制角色移動
- **逐步升級的難度**：迷宮尺寸變大、障礙物增多、時間限制縮短
- **沉浸式體驗**：鮮明的視覺效果和即時音效反饋
- **即時決策**：應對移動的障礙物，做出快速判斷

## 如何遊玩

1. 打開 `index.html` 文件或訪問遊戲網址
2. 點擊「開始遊戲」按鈕
3. 使用鍵盤方向鍵(↑↓←→)或WASD控制角色移動
4. 避開障礙物，在時間耗盡前到達終點
5. 成功通關後，難度會自動提升

## 遊戲規則

- 撞到障礙物或時間用盡，遊戲結束
- 每過一關，迷宮尺寸增大、障礙物增多、時間縮短
- 從第二關開始會出現移動的障礙物
- 玩家速度會隨關卡提升

## 技術實現

- 使用HTML5 Canvas繪製遊戲界面
- JavaScript實現遊戲邏輯
- 純前端實現，無需後端支持

## 本地運行

只需用瀏覽器打開 `index.html` 文件即可開始遊戲。
